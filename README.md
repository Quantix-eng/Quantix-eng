# Loïc Moche

I am a student at LFI Samuel Beckett (Dublin) working at the intersection of cognitive computing, LLM architecture, and bioinformatics. 

My work focuses on developing autonomous systems and exploring the cognitive boundaries of large language models.

## Current Research & Implementations
* **LLM Metacognition**: Investigating self-correction mechanisms and consensus logic in frontier models.
* **Bioinformatics**: Exploratory scripts and data pipelines analyzing genetic sequences via machine learning models.
* **Cognitive Systems**: Architecture and algorithms behind BrainPlanner, focusing on real-world routine validation using computer vision/agentic workflows.

## Technical Focus
* **Core**: Python (PyTorch, NumPy), TypeScript, C/C++
* **Interests**: Agentic LLM Orchestration, Mechanobiology, Systems Architecture
